⛨ Security
Sensor driver & Windows protections
Vexis reads CPU, fan and memory sensors through the PawnIO driver. PawnIO is signed and works with all Windows protections left ON — Vexis does not change Memory Integrity, Virtualization-Based Security or the Vulnerable Driver Blocklist.

Older Vexis versions switched those protections off. If they show OFF below, you can turn them back on here (a Windows restart is required).
